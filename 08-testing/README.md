# 08 — Software Testing

## Overview

This section contains exercises and examples demonstrating software testing principles.

## Learning Objectives

* Understand automated testing.
* Write unit tests.
* Test functions using assertions.
* Understand integration testing.
* Test REST APIs.
* Handle edge cases.
* Improve application reliability.

## Organization

* `unit-testing/` — Tests for individual functions.
* `integration-testing/` — Tests involving interacting components.
* `api-testing/` — Tests for API endpoints.
